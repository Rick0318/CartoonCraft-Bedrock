# CartoonCraft — Bedrock Edition

Add-on pack para **Minecraft Bedrock Edition** con estética cartoon.

## Contenido

| Módulo | Descripción |
|--------|-------------|
| `CartoonCraft_AnimationsMod` | Add-on con animaciones cartoon para el jugador |
| `CartoonCraft_BossPetsMod` | Add-on que permite domesticar jefes como mascotas |
| `CartoonCraft_TexturePack_Bedrock` | Texture pack con texturas estilo cartoon |

## Requisitos

- Minecraft Bedrock Edition 1.20+
- Experimental features habilitadas (según el add-on)

## Instalación

### Opción A — Instalación directa (recomendada)

1. Descarga el archivo `.mcpack` o `.mcaddon` desde la sección [Releases](../../releases).
2. Haz doble clic en el archivo — Minecraft lo importará automáticamente.
3. Activa el pack en tu mundo desde **Configuración → Recursos / Comportamiento**.

### Opción B — Manual

1. Copia la carpeta del behavior pack a:
   `Android: /games/com.mojang/behavior_packs/`
   `Windows: %AppData%\Minecraft\behavior_packs\`
2. Copia la carpeta del texture pack a la carpeta equivalente de `resource_packs`.
3. Actívalo en tu mundo.

## Estructura del proyecto

```
CartoonCraft_AnimationsMod/bedrock/       → animations add-on
CartoonCraft_BossPetsMod/bedrock/         → boss pets behavior pack
CartoonCraft_TexturePack_Bedrock/         → texture pack
```
